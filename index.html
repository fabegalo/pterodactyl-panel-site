Official Android companion for Pterodactyl servers

Control your game server from anywhere.

Pterodactyl Panel Mobile lets you monitor status, run console commands, create backups, and browse files directly from your phone.

Get on Play Store How setup works

Live Dashboard

Track server status, CPU, memory, disk usage, players, and ping in one screen.

Console Commands

Send commands remotely and follow console output in real time.

Backups

Create, list, and delete server backups with a simple and safe flow.

File Manager (Alpha)

Browse folders and files remotely. Feature is active and under continuous evolution.

Flexible Login

Supports API URL, domain, and direct IP address with optional custom port.

Multilanguage

Available in English, Portuguese, German, Spanish, Indonesian, Italian, Malay, Russian, and Thai.

Setup in 3 steps

  1. Open the app and enter your Pterodactyl API URL (or server IP).
  2. Paste your API key from your panel account.
  3. Select your server and start managing it remotely.

Accepted examples: panel.example.com, https://panel.example.com, 192.168.0.10, http://192.168.0.10:8080.
